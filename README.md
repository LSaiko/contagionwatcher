# ContagionWatcher

> Real-time U.S. disease surveillance — CDC data, no login required.

**[→ Open Live Dashboard](https://contagionwatcher.health)**

---

## What Is This?

ContagionWatcher is a public health dashboard that pulls live data directly from the
**CDC National Notifiable Diseases Surveillance System (NNDSS)** and presents it in one
clean, filterable interface.

The information that used to require navigating 10+ government pages — now in under 10 seconds.

---

## What It Shows

| Feature | Detail |
|---|---|
| **National disease trends** | 22 notifiable diseases, ranked by current case count |
| **Period filters** | Switch between Last 7 Days, 30 Days, 90 Days, or 1 Year |
| **State-level lookup** | Type any state, city, or abbreviation — get CDC case counts for that location |
| **Trend direction** | Rising / Stable / Declining vs. the prior equivalent period |
| **AI situation report** | Daily plain-language summary generated by Claude (Anthropic) |
| **CSV export** | Download disease data for any state or nationally, any period |
| **Activity map** | Choropleth of disease intensity across all 50 states + D.C. |

---

## Data Source

All public disease data comes from the **CDC NNDSS open dataset**:

- **API:** `https://data.cdc.gov/resource/x9gk-5huc.json`
- **Updated:** Every Friday (MMWR week)
- **License:** CDC Open Data — Public Domain
- **Coverage:** All U.S. states, 22+ nationally notifiable diseases, 2014–present

Case counts are confirmed notifiable disease reports — the same figures published in the
CDC's weekly Morbidity and Mortality Weekly Report (MMWR).

> **Not included in NNDSS:** HIV/AIDS, COVID-19, Influenza, Lyme Disease, and Norovirus
> are tracked in separate CDC systems (HIV Surveillance Report, COVID Tracker, FluView,
> NNDSS Table II, respectively).

## How It Compares

| | ContagionWatcher | VirusWatcher | Raw CDC |
|---|---|---|---|
| Free, no login | ✓ | Unclear | ✓ |
| U.S. state-level data | ✓ All 50 | Country-level only | ✓ Buried |
| Direct CDC source | ✓ NNDSS API | Aggregated | ✓ Primary |
| Period filters (7D–1Y) | ✓ | Not documented | Fixed MMWR |
| CSV export | ✓ Per state | Not public | Bulk only |
| AI summary | ✓ Daily | Alert flags only | None |
| Trend calculation | ✓ vs prior period | Severity only | None |
